## Description of the Project
The Daily Slice is an application that allows customers to create fully customized sandwich orders, including bread type, toppings, side sauces, drinks, and chips.
The application uses object-oriented programming principles to manage orders, calculate prices, display order details, and validate customer purchases.
Completed orders are saved as receipt files in a receipts folder, with each receipt named using the date and time the order was placed.

## User Stories
- As a customer, I want to view a home screen menu so that I can start a new order or exit the application.
- As a customer, I want to start a new order so that I can begin adding items I want to purchase.
- As a customer, I want to review my full order before checkout so that I can make sure everything is correct.
- As the business, I want each completed order saved as a receipt file so that we have a record of every purchase.
- As the business, I want customers with zero sandwiches to still purchase chips or a drink so that every order contains at least one item.

## Setup
1. Open IntelliJ IDEA
2. Create a new Java project or open the existing project folder.
3. Add the project files to the src folder.
4. Build and run the TheDailySlice.java file.

### Prerequisites

- IntelliJ IDEA: Ensure you have IntelliJ IDEA installed, which you can download from [here](https://www.jetbrains.com/idea/download/).
- Java SDK: Make sure Java SDK is installed and configured in IntelliJ.

### Running the Application in IntelliJ

Follow these steps to get your application running within IntelliJ IDEA:

1. Open IntelliJ IDEA.
2. Select "Open" and navigate to the directory where you cloned or downloaded the project.
3. After the project opens, wait for IntelliJ to index the files and set up the project.
4. Find the main class with the `public static void main(String[] args)` method.
5. Right-click on the file and select 'Run 'YourMainClassName.main()'' to start the application.
